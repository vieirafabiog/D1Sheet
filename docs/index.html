The Architecture Gap

Why build D1Sheet?

Modern edge SQL meets universal enterprise connectivity without managing servers or paying for idle cloud instances.

📊

Spreadsheets

Great for prototyping, but Google Sheets slows down past a few thousand rows and lacks real relational constraints.

  • ⚠️ Slow syncs on large tables
  • ⚠️ No foreign keys or ACID transactions
  • ⚠️ API rate limits under concurrent users
🖥️

Traditional SQL Servers

PostgreSQL or SQL Server require always-on VMs, connection pools, static IPs, and firewall rules opened to external clouds.

  • 💸 Monthly fixed server costs even when idle
  • 🔧 Complex VPC, SSL & IP allowlist setup
  • 🌍 Single-region latency spikes
⚡

D1Sheet + Cloudflare D1

Serverless SQLite replicated globally on Cloudflare Edge, speaking fluent OData v4 for AppSheet, Power BI, and Excel.

  • ✅ Generous free tier (5M reads / 100k writes)
  • ✅ Instant HTTP/HTTPS endpoint, zero firewalls
  • ✅ 100% parameterized SQL & dynamic $metadata
Under The Hood

Every Request in 4 Edge Steps

01 / SECURITY

Timing-Safe Auth

Validates Basic Auth headers via SHA-256 constant-time XOR comparison.

02 / PARSER

AST Query Parser

Tokenizes $filter, $select, and $orderby into a strict syntax tree.

03 / COMPILER

Parameterized SQL

Compiles queries using bound ? parameters—immune to SQL injection.

04 / RESPONSE

D1 + OData Envelope

Executes on D1 SQLite and returns OData v4 JSON with @odata.nextLink.

          Zero to Production
          
Deploy in 5 Minutes

          

            Six terminal commands to launch your serverless OData gateway on Cloudflare.
          

        


        

          

            
1. Clone & Install

            
Download the repository and install Worker dependencies.

            

              npm install
              
            

          


          

            
2. Create D1 Database

            

              Provision your serverless SQLite instance and paste the database_id into wrangler.toml.
            

            

              npx wrangler d1 create d1sheet-db
              
            

          


          

            
3. Initialize Tables

            

              Push the sample Customers, Products, and Orders schema to your remote D1.
            

            

              npm run db:init:remote
              
            

          


          

            
4. Set Secret & Deploy

            

              Store your Basic Auth password as an encrypted Cloudflare Secret and publish.
            

            

              npx wrangler secret put BASIC_AUTH_PASS && npm run deploy
